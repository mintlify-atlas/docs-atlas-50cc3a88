## Updating Webinoly

### Check for Updates

```bash
# Check current version
sudo webinoly -version

# View full system info
sudo webinoly -info
```

### Update to Latest Version

```bash
# Update Webinoly
sudo webinoly -update

# The update process:
# 1. Downloads latest version
# 2. Backs up current configuration
# 3. Installs new version
# 4. Preserves all your sites and settings
```

<Warning>
  Always backup your sites before major updates:
  ```bash
  sudo backup -all
  ```
</Warning>

### Beta Releases

Test upcoming features:

```bash
# Switch to beta channel
sudo webinoly -update -beta

# Switch back to stable
sudo webinoly -update
```

## Upgrade Path

### From Older Versions

<Steps>
  <Step title="Backup Everything">
    ```bash
    # Create full backup before upgrading
    sudo backup -all
    ```
  </Step>
  
  <Step title="Check Compatibility">
    ```bash
    # Review current installation
    sudo webinoly -info
    
    # Check site status
    sudo site -list
    ```
  </Step>
  
  <Step title="Update Webinoly">
    ```bash
    # Perform update
    sudo webinoly -update
    
    # Verify new version
    sudo webinoly -version
    ```
  </Step>
  
  <Step title="Test Your Sites">
    ```bash
    # Verify all sites work
    curl -I https://example.com
    
    # Check logs
    sudo log example.com
    ```
  </Step>
</Steps>

### Breaking Changes

<Warning>
  Check the [release notes](https://github.com/QROkes/webinoly/releases) for any breaking changes before upgrading major versions.
</Warning>

**Common upgrade considerations:**

- PHP version compatibility
- Database engine changes
- Configuration file formats
- Command syntax changes
- Deprecated features

## Rollback Procedure

If you encounter issues after updating:

<Steps>
  <Step title="Stop Services">
    ```bash
    sudo service nginx stop
    sudo service php*-fpm stop
    ```
  </Step>
  
  <Step title="Restore Backup">
    ```bash
    # If you created a backup before updating
    sudo restore -all
    ```
  </Step>
  
  <Step title="Report Issue">
    [Create an issue](https://github.com/QROkes/webinoly/issues) with:
    - Version numbers (old and new)
    - Error messages
    - Steps to reproduce
    - System information
  </Step>
</Steps>
