# Introduction to Webinoly

Webinoly offers one of the most reliable configurations for hosting websites—deploy everything in a single step.

Install a complete LEMP stack (Linux, NGINX, MariaDB/MySQL, PHP) or individual packages tailored to your needs. Get an A+ grade on [Qualys SSL Labs Test](https://www.ssllabs.com/ssltest/) out of the box.

## What is Webinoly?

Webinoly is a command-line interface (CLI) tool designed to make NGINX web server management simple and efficient. Whether you're deploying a WordPress site, setting up a reverse proxy, or managing a full production server, Webinoly provides powerful commands to handle complex tasks with ease.

## Why choose Webinoly?

### Optimized for performance

Webinoly comes pre-configured with battle-tested NGINX settings, FastCGI caching, and support for the latest HTTP/3 protocol. Your sites will load faster and handle more traffic without manual optimization.

### Security first

Automatic SSL certificate generation and renewal through Let's Encrypt, secure default configurations, and built-in HTTP authentication ensure your sites are protected from day one.

### WordPress made easy

Create fully optimized WordPress sites with a single command. Support for multisite networks, domain mapping, external databases, and subfolder installations makes Webinoly the perfect tool for WordPress developers and agencies.

### Developer friendly

Powerful CLI commands, reverse proxy support for modern frameworks, and comprehensive backup tools make Webinoly an essential tool for developers managing multiple projects.
